# 记忆引擎 Demo

这是一个口述历史整理项目，已经接好了语音转写和大模型能力。

如果你收到的是完整项目文件夹，并且其中已经带有 `.env.local`，那么你不需要再填写任何 API Key，直接启动即可。

## 需要准备的环境

- Node.js 20+
- npm 10+

先检查：

```bash
node -v
npm -v
```

## 如何启动

在项目根目录执行：
```bash
npm install
npm run dev
```

启动成功后，打开浏览器访问：

```text
http://localhost:3000
```

## 如何使用

1. 进入首页，在聊天区和 AI 一起生成访谈提纲。
2. 在右侧 Markdown 编辑区修改提纲。
3. 点击下一步，上传本地访谈音频。
4. 进入项目页后，点击“立即开始整理”。
5. 等待整理完成后，可查看整理结果并导出 Word / TXT / JSON。

## 需要注意

- 请不要删除项目根目录下的 `.env.local`，里面已经配好了运行所需配置。
- 上传的音频和项目数据会保存在本地 `storage/` 目录下。
- 第一次启动如果稍慢，属于正常现象。
- Windows 下如果看到 `swc` 相关 warning，一般不影响运行。


### 启动失败

优先检查：

- 有没有安装 Node.js 20 以上版本
- 有没有先执行 `npm install`
- 项目根目录里的 `.env.local` 是否还在

### 页面能打开但整理失败

优先检查：

- 当前电脑网络是否正常
- API 服务当前是否可用
- 终端里是否有报错信息

二、典型使用场景
场景一（机构端）： 某省档案馆承接红色记忆工程，需整理200小时革命老兵访谈录音。工作人员通过机构端批量上传音频，系统自动完成转写、脱敏与结构化整理，审核员在平台内完成人工审校后，一键导出符合档案标准的Word文档入库。
场景二（个人端）： 王女士希望为85岁外婆录制一段口述回忆作为家族礼物。她通过个人端上传录音，平台自动生成温暖风格的文字回忆录，导出后可直接打印成册或分享给家人。
三、完整用户流程
第一步：用户注册
支持邮箱注册
注册时选择身份：个人用户 / 机构用户
机构用户需填写单位名称（Demo阶段不上传证明材料）
登录方式规划路径：
Demo阶段
邮箱注册（快速验证核心功能）
MVP阶段
手机号验证码（个人端主入口）
+ 邮箱注册（机构端主入口）
正式运营
微信一键登录（个人端）
+ 手机号 + 邮箱（机构端多选）
第二步：身份选择
采用"宽进严出"机制：
注册时：用户选择账号类型（个人/机构），无需资质证明即可使用基础功能
支持单向升级：个人账号可申请升级为机构账号，需提交资质认证材料；审核通过后历史数据完整迁移，userType字段由系统同步更新，权限同步升级
不支持降级：机构账号不可降级为个人账号（原因：机构端承担档案留存义务，降级将导致合规责任无法追溯）
机构账号通过资质认证后，解锁高级功能（批量处理/多角色协作/高级权限管理）
底层数据按账号类型双轨隔离，userType字段以当前账号类型为准

四、数据治理与合规说明
（已于2026年8月11日与项目负责人确认）
受访者撤回授权的处理方式： 知情同意书及撤回申请书作为法律文书予以保留，不删除。业务数据（音频、转写稿、整理稿）进行隔离锁定，不再用于任何分析、导出和展示。如用户明确要求彻底删除，平台承诺72小时内受理，7个工作日内完成所有数据删除操作。操作日志永久保留。
机构端档案留存期限： 高校科研类项目留存5年，官方文史档案类留存10年。
知情同意书签署方式： 不强制要求通过平台完成，优先采用线下手写签名或经认证的电子签平台完成签署；个人端特殊情况下可采用微信书面确认作为替代方式（详见第四步）。平台层面通过弹窗提示用户知悉隐私合规要求及敏感信息处理说明，弹窗具体内容由伦理审查负责人姚婷婷提供。

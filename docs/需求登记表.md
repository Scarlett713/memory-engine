## 一、总览

### 1.0 产品交付分层与展示目标（方向性备注）

- **交付分层（目标口径）**：
  - **免费体验**：AI 生成即交付，**无人工复核环节**；**不含成文稿导出（PDF）**。
  - **项目制 / 定制服务**：AI 初步处理 + 人工复核 + 多轮返修（**最多三轮审校修订**，非免费服务）；**含成文稿导出（PDF）**。

- **与现状的差异（须在 PRD 写清）**：当前实现**不分层** —— 所有项目都必经人工审校（`workflow` 的 `manual_review` 步，`src/lib/types/project.ts:236-239`），且**导出门禁**强制脱敏标记全部确认（`src/app/api/projects/[projectId]/export/route.ts:69` 与 `.../[projectId]/route.ts:243` 共用 `countPendingSensitiveMarks`）。本分层为**目标口径**；落地前须裁决是否引入分层字段 / 分流开关。
- **下游引用**：REQ-17（人工复核完整工作流）、REQ-19（返修轮次上限三轮须与本条对齐）、REQ-18（脱敏人工确认门禁）、**REQ-15 / REQ-20（导出付费口径 + 成稿归档，见本条「导出 PDF = 付费能力」）**。

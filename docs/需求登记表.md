## 一、总览

### 1.0 产品交付分层与展示目标（方向性备注）

- **交付分层（目标口径）**：
  - **免费体验**：AI 生成即交付，**无人工复核环节**；**不含成文稿导出（PDF）**。
  - **项目制 / 定制服务**：AI 初步处理 + 人工复核 + 多轮返修（**最多三轮审校修订**，非免费服务）；**含成文稿导出（PDF）**。
  - **导出 PDF = 付费能力**（分层口径**唯一真值来源**，供 REQ-15 / REQ-20 引用）。**现状差异**：现有 `Word / TXT / JSON` 导出**已实现且免费**（`src/components/projects/project-export-panel.tsx:23`、`docs/architecture/记忆引擎_技术架构文档_骨架v0.1.md:248`）；PDF 导出**尚未实现**（REQ-20 中期走 `window.print()`），本期不做支付集成（REQ-20 / REQ-19「不做」）。
- **与现状的差异（须在 PRD 写清）**：当前实现**不分层** —— 所有项目都必经人工审校（`workflow` 的 `manual_review` 步，`src/lib/types/project.ts:236-239`），且**导出门禁**强制脱敏标记全部确认（`src/app/api/projects/[projectId]/export/route.ts:69` 与 `.../[projectId]/route.ts:243` 共用 `countPendingSensitiveMarks`）。本分层为**目标口径**；落地前须裁决是否引入分层字段 / 分流开关。
- **下游引用**：REQ-17（人工复核完整工作流）、REQ-19（返修轮次上限三轮须与本条对齐）、REQ-18（脱敏人工确认门禁）、**REQ-15 / REQ-20（导出付费口径 + 成稿归档，见本条「导出 PDF = 付费能力」）**。
- **展示目标（评委）**：向评委展示**完整、精美、全流程**的设计能力；近期 MVP 聚焦「入口与体验」，最终目标是完整闭环「**AI 处理 + 人工复核 + 用户交付**」。既有话术出处：`docs/architecture/记忆引擎_技术架构文档_骨架v0.1.md`（`【评委追问点】` `:17` / `:410` / `:1087`）。

## 四、已知局限（现存事实，不随本批次修复）

> 下列为**当前代码事实**中已知的不足，登记备查；除注明外均不在本批次修复。

1. **JSON 单文件存储的并发上限**：项目数据以单文件 JSON 保存，写入侧虽已加固（原子写 + 串行队列 + 损坏隔离 + dev / build 目录隔离，见 §二-2），但并发编辑 / 多写者场景无数据库级保障 → **REQ-17 的后台并发编辑开工前需评估**。
2. **`maskByRules` 的 name 规则无实现分支**：规则选项在 `src/lib/oral-history.ts` 中暴露，但 name 类规则实际不生效。
3. **`isExcerptMatchedByRules` 对地址前缀存在漏报**：以「地址前缀」形式出现的片段可能不被判定命中，导致复核面板漏提示。
4. **存量正面情绪样例与新口径不一致**：现有 `emotionalSignals` 含 notice 级正面情绪（如「幽默与乐观」「輕鬆愉快」），与「只收负面情绪」的新口径不符；**不迁移存量数据**，仅新链路按新口径产出。
5. **提纲 → 上传的携带依赖会话态**：`?outline=1` + `sessionStorage`，跨设备 / 清缓存即丢失 → 由 REQ-15 草稿箱解决。
6. **单通道转写无法做说话人分离**：Web Speech 与讯飞均为单通道，无法区分主持人与受访者（已在 PRD §10 列为不做）。
7. **转写精度受限于 ASR 引擎，方言 / 口音场景尤其突出**：与第 6 条不同 —— 第 6 条是**说话人分离**，本条是**识别精度**。转写走讯飞（provider 可在 `xfyun` / `volcengine` / `mock` 间切换，见 `src/lib/providers/transcription/index.ts:6-16`），语言参数目前只在**上传页**可选（`src/components/upload/interview-upload-form.tsx:53-61`：普通话 / 英语 / 粤语 / 四川话 / 上海话 / 河南话），provider 侧仅缺省回落 `language: "cn"`（`xfyun-transcription-provider.ts:119`）。**未做方言专项 A/B 测试**、无准确率基线（现有断言只校验该语言选项的 UI 标签存在 —— `tmp/cdp-req14-consent.mjs:302-303`，不验识别精度）；PRD §0 第 5 条与 §10 已把「讯飞流式 IAT 及任何新的付费识别能力」列为本期不做。影响面：转写稿是文稿整理（`src/lib/server/process-project.ts`）与 REQ-22 追问的输入，也决定 UI-17 转写稿展示的价值；带口音 / 方言的老年受访者场景风险最高。竞品小鹿光年把「方言识别能力」作为 ASR **选型硬指标**并要求**持续 A/B 对比**（`docs/竞品-小鹿光年.md` §2.1 / §四映射表）。

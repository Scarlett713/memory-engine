## 二、REQ-16（候选）：首页与新建流程重构

- **来源**：任 反馈（2026-10-03）
- **背景/问题**：
  1. 首页当前并列两个入口按钮（「新建访谈项目」→ `/upload`、「新建访谈（含提纲生成）」→ `/projects/new/outline`），用户不知道两者差别。
  2. 首页把所有项目平铺在下方列表，缺少「新建 / 草稿 / 已发表」的功能分区。
  3. 处理台入口不清晰，转写/整理/导出进度不可见（需点进详情页才知道）。
  4. 填完基本信息但未走完流程时，没有中途保存路径（关联 REQ-15）。
- **目标与范围**：
  - 新建改为**单一入口**：先进「基本信息」（主题 / 受访者 / 场景）→ 再选采集方式「实时访谈」或「音频上传」，**不在首页并列两个按钮**。
  - 与 REQ-14 的 D1=C（表单为主、对话细化）对齐：AI 访谈走同一套基本信息，信息再喂给提纲生成。
  - 首页参考微信公众号创作者中心的信息架构：**新建 / 草稿 / 已发表（历史项目）** 三区块，项目不再无差别堆在底部。
  - 处理台入口与进度可见：列表/卡片直接暴露当前步骤与进度（转写中 / 整理中 / 待审校 / 可导出）。
- **参考页面**：微信公众号创作者中心（「新的创作 / 草稿 / 已发表内容」三区块结构）—— 任 提供。
- **验收要点（草案，待 PRD 细化）**：
  - 首页只有 1 个「新建」主动作，无并列的第二个新建按钮。
  - 三区块（新建/草稿/已发表）在桌面与窄屏下均可明确区分。
  - 历史项目卡片可直接看到当前处理步骤，点击一步进入处理台。
- **风险提示（与既有验收脚本冲突）**：`tmp/cdp-req13-outline.mjs` 的 13-E 断言首页同时存在「新建访谈（含提纲生成）」与「新建访谈项目」两个入口；`tmp/measure-375.mjs` 以首页 header 高度为基线。REQ-16 动首页时这三个脚本（另含 `tmp/cdp-req13-crosscut.mjs`）需同步改写。
- **待确认项**：
  - 「草稿」与「已发表」的判定标准（按 `ProjectStatus` 映射还是新增业务态？注意本项目数据层枚举为固化约束）。
  - 「已发表」是否等价于 `ready_to_export` + 已导出。
  - 与 REQ-14「确认提纲后才建项目」的冲突点：未确认的提纲是否落入「草稿」区块。

## 三、REQ-15（候选）：草稿箱

- **来源**：任 反馈（2026-10-03）
- **背景/问题**：用户上传音频中途、或填完基本信息但未完成整个流程时，没有保存草稿的能力，刷新/离开即丢失。
- **目标与范围**：
  - 支持「音频上传中途」与「信息填写未完成」两种中断场景下保存草稿。
  - 草稿可作为「继续未完成流程」的入口。
- **依赖**：**REQ-16 信息架构定型后再详细设计**（草稿归属哪个区块、如何与「新建」衔接）。
- **现状参考**：REQ-13 的提纲草稿已用 `sessionStorage`（`src/lib/outline-session.ts`，键 `memory-engine-outline-session`），登出时清理；`tmp/cdp-req13-crosscut.mjs` 已覆盖该行为。
- **待确认项**：
  - 草稿的存储位置（本机 `sessionStorage`/`localStorage` vs 后端持久化）——跨设备草稿当前属明确未做边界。
  - 音频二进制是否纳入草稿（涉及存储层，当前为固化约束，默认不纳入）。

## 四、UI-02（候选）：个人账户隐藏机构/单位字段

- **来源**：任 反馈（2026-10-03）
- **背景/问题**：上传表单「整理机构 / 机构或单位」对个人注册用户无意义。
- **目标与范围**：
  - 按账户类型差异化显示：机构账户保留并保持必填；个人账户**默认隐藏或改为选填**。
  - 账户类型来源：代理注入的 `x-user-type`（`personal` / `institution`），前端读 `useAuth().user.userType`；首页已用它渲染「个人版 / 机构版」文案（`src/components/home/home-dashboard.tsx:64`），可作为既有范式。
- **验收要点（草案）**：
  - 个人账户进入表单时看不到「整理机构」必填项。
  - 机构账户行为与现状一致（不回归）。
  - 账户类型未就绪（`useAuth().loading`）时不出现字段闪烁。
- **待确认项**：个人账户是「完全隐藏」还是「折叠为选填」；已填值在账户类型变化后如何处理。

## 0. 一句话概述

在 AI 访谈的**作答态**（用户正在回答时）把「当前问题」以一张静态小卡固定显示在实时字幕卡**正上方**，让用户讲话途中随时可瞄一眼问题，不必等 AI 下一轮、也不必靠 `paused` 或重进页面才能看到。

## 1. 目标与非目标

**目标**

1. 作答态**始终可见**当前问题，且**题号可读**（第几题 / 共几题）。
2. 与 `ai_asking` / `paused` **同一套视觉语义**（眉标 ＋ 题号胶囊 ＋ `surface-card` 正文），切相位时不出现「同一信息两种长相」。
3. 单文件、零状态、零接口、零依赖；音频录制 / 上传 / 整理全链路**行为完全不变**。

**非目标**

- 不做历史问答列表、不做「上一问 / 下一问」翻页（另立需求）。
- 不做折叠 / 展开 / 悬浮 / 复制 / 朗读等交互（Q2 已否决折叠）。
- 不做 2 行截断后的「查看全文」出口（如需，另立；见 §8 风险 ③）。
- 不改 `ai_asking` / `paused` / `error` 三块的任何一行（**0 hunk**）。
- 不改字幕卡 `min-h-[14rem]`、不改操作行 `mt-auto` 沉底链（`:984-993` 的既有注释成因不动）。
- 不改 BUG-09 面：`fetchNextQuestion`（`:818-900`）、`AbortController`（`:819-823`）、错误 UI（`:1261-1277`）。
- 不引入新依赖、不改 `globals.css`、不加新色值 / 新 class。

## 3. 定稿形态

### 3.1 位置与顺序（作答态，自上而下）

1. 眉标行：「实时字幕」＋「录音中 · mm:ss / 未录音」（**现状不动**）
2. 麦克风权限横幅（仅有 `permissionError` 时，**现状不动**）
3. **【新增】问题卡**：眉标「当前问题」＋ 胶囊「第 x / y 题」＋ 问题正文（限 2 行）
4. 实时字幕卡（`min-h-[14rem]`，**现状不动**）
5. 操作行「结束回答 / 暂停」（`mt-auto` 沉底，**现状不动**）

> **为什么放在权限横幅之后**：错误提示的信息优先级高于参考信息，保留其贴近顶部的现有位置；同时问题卡仍**紧贴字幕卡上方**，满足 Q3「固定在字幕卡上方」。

### 3.2 逐字结构与样式（定稿，可直接落码）

```tsx
{/* UI-32：作答态固定显示当前问题 —— 总管 2026-11-18 裁决：带题号、
    限 2 行截断不折叠、固定在字幕卡上方且不随字幕滚动。
    只读 state，不新增 action；形态对齐 ai_asking / paused。 */}
<div className="surface-card rounded-[1.55rem] px-4 py-3">
  <div className="flex items-center justify-between gap-3">
    <p className="section-eyebrow">当前问题</p>
    <div className="tape-label">
      第 {state.questionIndex + 1} / {questionTotal} 题
    </div>
  </div>
  <p className="mt-2 line-clamp-2 text-sm leading-7 text-foreground">
    {state.currentQuestion || "（等待 AI 提问）"}
  </p>
</div>
```

**样式取值理由（逐条可核）**

| 项 | 取值 | 理由 |
|---|---|---|
| 容器类 | `surface-card rounded-[1.55rem]` | 与 `ai_asking:1137`、`paused:1241` 同一容器语义与圆角 |
| 内边距 | `px-4 py-3` | 比 `ai_asking` 的 `py-5` 更紧 —— 本卡是**参考信息**，主视觉仍是字幕 |
| 眉标 | `section-eyebrow` | 与「实时字幕」「当前问题」「已暂停」同一类（`globals.css:245`，无外边距，flex 行内使用与 `ai_asking:1131` 一致） |
| 题号 | `tape-label` | 与 `ai_asking:1132` 同类同形（`globals.css:276`，`inline-flex` 胶囊） |
| 正文 | `text-sm leading-7` | 比 `ai_asking` 的 `text-base leading-8` 小一级，配合 2 行上限压缩高度 |
| 截断 | `line-clamp-2` | Tailwind **v4 核心工具类**（无需插件），自带 `overflow:hidden` ＋ 省略号 |
| 空值兜底 | `（等待 AI 提问）` | 与 `ai_asking:1138` / `paused:1242` **逐字一致**，不新造第二套文案 |

> **不得**给该卡加 `soft-scroll` / `max-h` / 展开按钮 / `title`：Q2 已裁「限 2 行即封顶」，任何额外交互都属超范围。

### 3.3 题号口径（Q1）

- 当前题号：`state.questionIndex + 1`；总题数：`questionTotal`。
- 与 `ai_asking:1133` **逐字同源**，故两相位题号恒等，不会出现「问时 3/5、答时 2/5」的不一致。
- `questionTotal` 已含兜底（`Math.max(totalQuestions, state.questionIndex + 1)`），保证**分母不小于分子**；本 PRD **不重复实现**该兜底。
- 文案格式固定：`第 {n} / {m} 题`（斜杠两侧半角空格，与 `:1133` 逐字一致）。

### 3.4 截断规则（Q2）

- 正文最多 **2 行**，超出以省略号收尾（`line-clamp-2`）。
- **不提供**任何展开 / 折叠 / 悬浮全文入口；`state.currentQuestion` 原文不变、不截断存储（**纯视图截断**）。
- 1 行文本不占位拉伸（卡片高度随 1~2 行自适应，不设固定高度）。
- 中文长句按字符换行即可，**不加** `break-all`（避免英文单词被切断）。

### 3.5 固定与滚动（Q3）

- 问题卡**不进入**字幕卡滚动区，也不与 `captionText` 的增高联动：字幕只在自身卡内增长 / 滚动（`soft-scroll`），问题卡位置恒定。
- 问题卡**不吸顶**（不做 `sticky` / `fixed`）：随面板整体布局定位，页面级滚动时不额外占视口。

### 3.6 相位切换连续性

| 迁移 | 表现 |
|---|---|
| `ai_asking` → `user_answering`（点「开始回答」） | 问题文本与题号**保持不变**（同一 state），只是眉标区由「当前问题」变为「实时字幕」＋ 新卡常显；无空白闪断 |
| `user_answering` → `ai_thinking` | 新卡随分支卸载（`CenteredLoading` 接管），无残留 |
| `user_answering` → `paused` | 新卡卸载，`paused` 自带同形卡接管 ⇒ 同一信息**不双卡并存** |
| `user_answering` → `error` | 新卡卸载，错误 UI 接管（BUG-09 面 0 hunk） |

## 5. 高度预算与断点

**新增高度（单卡）**：眉标行 ≈ 1.2rem ＋ `mt-2` 0.5rem ＋ 正文 2 × 1.75rem ＝ 3.5rem ＋ `py-3` 1.5rem ⇒ **≈ 6.7rem（≈ 107px）**；面板 `gap-4`（`:1046`，1rem）再计入 ⇒ **≈ 7.7rem（≈ 123px）**。

| 视口 | 判定 | 结论 |
|---|---|---|
| PC（宽 ≥1024px、高 ≥768px） | 字幕卡 224px ＋ 新卡 107px ＋ 操作行 ＋ 页头，余量充足 | 不触发滚动 |
| 390 × 844 | 面板可用高度 ≈ 600px，内容 ≈ 480px | 不触发滚动 |
| 375 × 667（iPhone SE） | 面板可用高度 ≈ 430px，内容 ≈ 480px（**临界**） | **允许页面纵向滚动**；硬要求 = 操作行「结束回答 / 暂停」仍可滚动到并点击；字幕卡 `min-h-[14rem]` **不下调**（下调另立需求） |

> 断点策略：**所有视口同一形态**，不设 `md:` / `lg:` 分支 —— 本卡是 2 行静态文本，拆响应式只会增加维护面。

## 7. 验收标准（逐条可验，实施轮逐条打勾）

- **AC-1** 作答态显示问题卡：点「开始回答」后，眉标「当前问题」＋ 题号胶囊 ＋ 问题正文**同时出现**。
- **AC-2** 题号正确：与进入作答前 `ai_asking` 显示的题号**逐字相同**（`第 n / m 题`），且 `n ≤ m`。
- **AC-3** 空值兜底：人为置空 `currentQuestion`（或接口未回填）时显示 `（等待 AI 提问）`，与 `ai_asking` / `paused` 逐字一致。
- **AC-4** 2 行截断：问题文本 ≥ 60 字时**只显示 2 行 + 省略号**，无横向滚动、无第三行露出、无展开控件。
- **AC-5** 固定位置：字幕文本持续增长时，问题卡**不发生位移**（前后截图 y 坐标不变）。
- **AC-6** 顺序正确：存在权限横幅时，自上而下为「眉标行 → 权限横幅 → 问题卡 → 字幕卡 → 操作行」。
- **AC-7** 无关相位 0 变化：`ready` / `ai_asking` / `paused` / `error` 四块渲染与改前**一致**（`git diff` 中这四块 0 hunk）。
- **AC-8** 服务端 0 变化：`git status --porcelain` 的 `src/` 改动**只有 1 个文件**；`src/app/api/**`、`src/lib/**` 0 hunk。
- **AC-9** 探针：`node tmp/verify-bug09-next-question-timeout.mjs` **仍 exit 0**（与本 PRD 出稿前基线一致）。
- **AC-10** 高度预算：375 × 667 下可滚动到「结束回答」并点击；字幕卡 `min-h-[14rem]` 未被改写。
